# Browser demonstration

Open `index.html` in a desktop or mobile browser. Press **Request to cross** to see the simulated ESP32 behavior: a 10-second walk interval, blinking indicator, crossing animation, UART-style messages, and ignored requests while busy. Use **Reset simulation** to restart.

This is an interactive software simulation only. The challenge instructions explicitly require a physical ESP32 or STM32 board for Track B, so this can illustrate the idea but cannot replace the live hardware demo, FirmGen traceability report, or board UART evidence.
